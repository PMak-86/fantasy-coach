# Fantasy Coach — project website

A static, informational landing page for a **personal, non-commercial fantasy basketball analytics project**. The application is in development; this page does not claim to have Yahoo Fantasy API access.

## Publish on GitHub Pages

1. Log in to https://github.com/ and create a new **public** repository named `fantasy-coach` (use any existing GitHub account).
2. Upload `index.html` to the **root** of the repository, or create an `index.html` file and paste its contents. Commit the change to `main`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select **main** and **/(root)**, then **Save**.
5. When publishing completes, open **Visit site**. Your URL will follow the pattern `https://YOUR-GITHUB-USERNAME.github.io/fantasy-coach/`.
6. Verify that it opens publicly without login, then use that *actual working URL* in Yahoo’s **Website URL or App Store Details** field.

GitHub Pages may take several minutes to publish. The public site contains no passwords, tokens, private league data or personal contact information.

Helpful documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
